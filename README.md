# Discord Bot Landing Page

A modern and stylish landing page for a Discord bot project called Nova Bot.

## Features
- Premium-looking hero section
- Feature cards for moderation, music, tickets, and AI
- Animated stats section
- Clean call-to-action for inviting the bot

## Project Structure
- index.html — main page structure
- style.css — styling and animations
- script.js — interactive animations and counters
- assets/preview.png — preview image for the repository

## Run Locally
Open index.html in your browser, or use:

```bash
python -m http.server 8000
```

Then visit: http://localhost:8000
